# CSharp-Practice

A personal hands-on repository for learning and practicing **C# and .NET** from basic concepts to more advanced topics.

The goal of this repository is to learn concepts by writing code, experimenting with examples, and gradually building stronger understanding of C#.

---

## 📚 Topics Covered

- C# Basics
- Control Statements
- Arrays
- Object-Oriented Programming
- Constructors
- Inheritance
- Method Hiding
- Abstract Classes
- Sealed Classes
- Interfaces
- Partial Classes
- Static Classes
- Enums
- Delegates
- Events
- Exception Handling
- File Operations
- Generic Collections
- LINQ
- Attributes
- Async Programming
- Windows Forms
- Practical C# Programs
